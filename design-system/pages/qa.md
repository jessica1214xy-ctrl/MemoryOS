# 页面覆盖：自然语言问答入口 `/qa`（右侧面板 / 命令面板）

> 检索规则：先读 `../MASTER.md`，本文件为页面级差异与 5 态覆盖。

## 布局
- 形态 A（工作台）：右问答面板（360px，`--panel-width`），常驻首页右侧；顶部 `MessageSquare` 20px + 「问问你的记忆」输入 + 流式回答区。
- 形态 B（命令面板）：全局 `Cmd/Ctrl+K` 唤起居中浮层（`shadow-lg`），输入 + 实时结果，Esc 关闭，键盘上下选择。两形态共用同一组件与 Token。
- 回答块：顶部 2px 蓝→绿细线标记（AI 内容标识）；正文 `text-foreground`；来源引用区（每条 `Link` 16px + 设备图标 + 文案，可点击跳转来源时间线条目）。

## 关键组件
- 输入栏（`Search`/`ArrowUp`）、流式回答块、来源引用列表、思考指示、中止按钮、复制/追问操作。

## 5 态覆盖
| 状态 | 设计 |
|---|---|
| Loading | 思考中：回答区显示打字机占位 + 「预计 ~N 秒」+ 「中止」按钮（`X` 16px，可中断 `POST /api/v1/kb/query` 流） |
| Empty | 首屏：`Sparkles`/`MessageSquare` 引导 + 3 个示例提问（如「我这周和导师聊了什么」「标注了哪些论文」「下周有什么要跟进」）；无「Welcome to」占位 |
| Error | 失败：`AlertTriangle` + 错误分类（模型/网络/权限）+ 「重试」+ 降级（展示已缓存片段或建议改写问题） |
| Populated | 流式回答（逐 token 渲染）+ 来源引用 + 操作（复制 `Copy` / 追问输入框）；回答完成高亮 + 复制成功 toast |
| Edge | 超长输出截断「展开完整」+ 成本上限提示（「本次已达额度上限，简化问题可继续」） |

## 交互
- 输入发送：`ArrowUp` 或 Enter → 触发流式；流式期间显示「中止」。
- 来源引用：每条可点击 → 跳转对应时间线/知识库来源（跨页联动）。
- 复制：点 `Copy` → 写入剪贴板 + toast「已复制」。
- 追问：回答下方输入框，保持上下文（多轮）。

## 动效（150ms 收敛，无弹跳）
- 回答逐 token 淡入；来源引用 hover `text-primary`；面板/命令面板 200ms 缓入。

## 响应式
- 桌面：右面板常驻；移动：面板→底部上滑抽屉或全屏命令面板；输入栏 sticky 底部。

## 验收对应（PRD §8）
- Given 用户输入问题并发送，When `/api/v1/kb/query` 流式返回，Then 答案逐 token 渲染且每条来源引用可点击跳转。
- Given 回答生成中，When 用户点「中止」，Then 流中断且保留已生成部分 + 可追问。
- Given 回答失败，When 展示错误，Then 显示分类 + 重试 + 降级方案。
