# PRD · 扩展设备记忆代理（终端集成与跨端协调）

> 版本：v1.0 ｜ 基于：集成与协调方案（docs/00-integration-strategy.md）
> 范围：在现有 Web MVP 基础上，新增微信小程序、原生 App 终端，并实现多端统一身份/数据/体验协调。

---

## 1. 产品定义

**一句话**：把设备记忆代理从"浏览器里的 MVP"扩展为"长在用户真实终端上的第二大脑"——在微信、手机系统、网页之间自动捕获上下文，并在任意设备无缝续接与提醒。

**核心问题**：用户在微信、原生 App、网页间的上下文仍碎片化；现有 MVP 数据靠模拟，真实价值需接入真实终端。

---

## 2. 目标用户与场景

- **主用户**：研究生 / 知识工作者，高频使用微信沟通与多设备切换。
- **场景**：
  - 微信里和导师确认实验方向 → 自动沉淀为"上次聊到哪"；
  - 微信收藏论文 3 天未读 → 主动提醒；
  - 在电脑看论文，手机打开自动续接断点；
  - 原生 App 监听剪贴板/通知，无感补全记忆。

---

## 3. 功能规格（Functional Spec）

### F1 微信小程序端（Primary）
- 微信 OAuth 登录并合并账户；
- 捕获：微信聊天关键片段（经授权）、微信收藏、微信文件转发；
- 提供时间线 / 知识库 / 提醒 / 问答四模块（响应式小程序版）；
- 支持把记忆以会话卡片分享回微信。

### F2 原生 App 端（Secondary / Pro）
- 手机号/微信联合登录；
- 系统级捕获：剪贴板、通知、跨 App 文件/网页收藏（按授权）；
- 后台增量同步、离线记忆；
- 系统通知通道分发提醒。

### F3 多端统一身份（协调机制）
- `user_id` 主键；微信 OpenID / 设备 ID / 手机号映射合并；
- 设备注册与能力登记；按设备/应用粒度授权与撤销。

### F4 多端统一数据（协调机制）
- 中心化同步；异构数据统一映射为 `TimelineEvent`；
- 语义合并、离线队列、服务端向量索引；
- **跨端续接**：断点事件按 `device_source` 返回并支持一键续接。

### F5 多端统一体验（协调机制）
- 统一 Design Token 与组件库；
- 四模块心智模型一致；
- 提醒三通道（系统通知 / 订阅消息 / 站内卡片）去重分发。

### F6 统一提醒分发
- 当前活跃设备优先推送；处理状态跨端即时同步；去重避免打扰。

## 4. 用户故事（User Stories）

| 编号 | 角色 | 故事 | 验收 |
|------|------|------|------|
| US-1 | 研究生 | 作为微信用户，我希望在微信里就能把和导师的沟通沉淀为记忆，以免遗忘 | 授权后微信聊天/收藏自动进入时间线 |
| US-2 | 研究生 | 作为多设备用户，我希望在手机打开时自动续接电脑的断点 | 打开即见"上次在电脑做到哪"+续接入口 |
| US-3 | Pro 用户 | 作为重度用户，我希望系统无感补全我的剪贴板/通知上下文 | 原生 App 授权后后台增量同步 |
| US-4 | 用户 | 作为被提醒的人，我希望只在当前设备收到一次提醒 | 提醒三通道去重，处理状态跨端同步 |
| US-5 | 隐私敏感用户 | 作为注重隐私的人，我希望按设备关闭捕获 | 设备/应用级开关与一键撤销生效 |

---

## 5. 优先级（MoSCoW + RICE 摘要）

| 功能 | 优先级 | 理由 |
|------|--------|------|
| F1 微信小程序 | P0（Must） | 触达与核心价值最高，成本最低 |
| F3 统一身份 | P0 | 多端协调前提 |
| F4 统一数据 + 续接 | P0 | 核心价值闭环 |
| F5/F6 统一体验与提醒分发 | P1（Should） | 体验完整度 |
| F2 原生 App | P1 | 深度能力，投入较高 |
| Phase2 其他小程序 | P2（Could） | ROI 偏低 |

---

## 6. 验收标准（摘要）

- 微信端：授权后聊天/收藏可在 30s 内出现在时间线；
- 续接：跨设备打开，断点卡片可见且可一键续接；
- 身份：同一用户多端登录后记忆合并，无重复账户；
- 提醒：同一提醒至多触达一次，处理状态 5s 内跨端同步；
- 隐私：设备级关闭后该设备数据停止上报。

---

## 7. 非功能需求与约束

- 合规：微信数据最小化采集、明示授权、可撤销；
- 性能：事件上报端到端 < 30s，时间线首屏 < 1.5s；
- 离线：原生 App 断网可本地队列，恢复后增量上报；
- 平台：小程序一套框架；原生 App 建议跨端框架控制双端成本。

---

## 8. Out-of-Scope（本期不做）

- 其他小程序平台（Phase 2）；
- 知识图谱 / 多模态理解（P2）；
- 团队/企业多人工享记忆（单独产品线）；
- 真实微信/邮箱后台爬虫式抓取（仅限授权内上下文）。
