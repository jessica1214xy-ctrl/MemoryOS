# 设计稿件说明 · 扩展设备记忆代理（多端）

> 配套：PRD（docs/01）、集成方案（docs/00）。延续现有 Design Token 与"Calm Continuity"语言：统一 SVG 图标（Lucide）、零硬编码色、禁紫粉渐变、禁 AI 模板味。

---

## 1. 设计原则

- **一致优先**：四模块心智模型在所有终端一致，仅做响应式裁剪；
- **能力梯度**：小程序展示核心闭环，原生 App 额外暴露系统级开关；
- **无感捕获，显性可控**：自动记忆默认安静运行，隐私开关始终可及；
- **续接显性化**：跨设备断点必须用户确认再跳转，不打断。

## 3. 关键页面说明

### 3.1 跨设备时间线（核心）
- 顶部：设备筛选 chips（实验室电脑 / 手机 / 平板 / 微信 / 邮箱 / 本机系统）；
- 列表项：设备图标（Lucide，16/20/24px）、时间戳、事件类型、标题、摘要；
- 断点项：右上角"可续接"标记，点击展开"在 X 设备做到哪"+一键续接；
- 空/加载/错误/正常/边界五态齐备（沿用现有 States 组件）。

### 3.2 个人知识库
- 顶部：自动记忆卡（"上次和导师聊到哪""实验做到哪一步"）；
- 右侧/下方："问问你的记忆"对话框，回答带可点击引用（跳转原始事件）；
- 演示模式标注"演示模式"，接真模型后自动去除。

### 3.3 主动提醒
- 提醒卡：标题 + 正文 + 触发来源 + 忽略/稍后/已处理；
- 已处理状态跨端即时同步（乐观更新 + 服务端确认）。

### 3.4 设备与隐私（原生 App 主设）
- 设备列表：设备名、类型、最近活跃、采集能力；
- 授权开关：按设备/按应用粒度，一键撤销并停止上报。

---

## 4. 核心交互流程

### 4.1 微信上下文自动捕获
微信授权 → 监听收藏/转发/授权聊天片段 → 映射为 `TimelineEvent(device_source=wechat)` → 增量上报 → 时间线出现 → 触发相关提醒（如"3 天前收藏未读"）。

### 4.2 跨设备续接
用户在设备 B 打开 → 服务端按 `user_id` 取最新带断点事件（含 `device_source=A`）→ 首页顶部展示"上次在 A 做到哪" → 用户点击确认 → 跳转对应上下文续接。

### 4.3 主动提醒三通道去重
事件触发提醒 → 判断当前活跃设备 → 仅向活跃设备发通道通知（系统通知/订阅消息/站内卡片）→ 任一处处理 → 状态回写 → 其余通道标记已处理不再打扰。

### 4.4 隐私撤销
用户关闭某设备捕获 → 本地立即停止队列上报 → 服务端保留历史（可导出/删除）→ 新数据不再来自该设备。

## 5. 一致性规范

- 复用 `design-system/design-tokens.json` 全部 Token；
- 图标：仅 Lucide，禁止 emoji；尺寸 16（行内）/20（按钮）/24（独立）；
- 颜色：品牌蓝 `#1a56db`/`#3b82f6`、AI 绿 `#10b981`、中性灰阶，全部走 Token；
- 字体：Manrope + Noto Sans SC + JetBrains Mono（代码/ID）；
- 动效：prefers-reduced-motion 友好，禁用弹性缓动。
