# 产品介绍手册 · 扩展设备记忆代理

> 本文档含两个视角：**A. 用户版**（对外传播/应用商店/落地页）、**B. 内部团队版**（对齐定位、路线图与协作）。

---

## A. 用户版（对外）

### A.1 一句话介绍
**MemoryOS —— 长在微信和手机里的第二大脑。** 自动记住你在微信、电脑、手机之间散落的研究上下文，并在对的设备、对的时间提醒你、帮你续上。

### A.2 它能帮你做什么
- **自动沉淀微信记忆**：和导师聊到哪、收藏了什么论文，授权后自动进入你的时间线；
- **跨设备续接**：在电脑看到一半，手机打开自动接上断点；
- **主动提醒**：3 天前收藏的论文还没读？该回导师邮件了？它替你记着；
- **随时问答**：用大白话问"实验 B 的结论是啥"，答案带引用、可跳回原文。

### A.3 怎么开始
1. 微信搜索/打开 MemoryOS 小程序，授权登录；
2. 开启"微信上下文捕获"，你的记忆就开始自动积累；
3. 想要无感自动记忆，可安装原生 App（Pro），开启系统级捕获。

### A.4 隐私承诺（用户最关心）
- 仅在你**授权范围内**捕获，可随时按设备/应用关闭；
- 数据用于服务你自己，不做模型训练（生产环境核验"不训练"承诺）；
- 支持一键导出与删除。

### A.5 常见问题（FAQ）
- Q：微信聊天会被全部读取吗？ A：不会，仅捕获你授权的关键片段，且可随时关闭。
- Q：换手机记忆还在吗？ A：在，记忆在服务端按账户归集，换端登录即同步。
- Q：免费吗？ A：小程序核心能力免费；原生 App 系统级无感捕获为 Pro 能力。

## B. 内部团队版（对齐用）

### B.1 产品定位
面向研究生/知识工作者的**个人上下文记忆代理**；当前阶段主打"微信小程序首触 + 原生 App 深度"的双形态策略，差异化在于**真实终端捕获 + 跨端续接 + 主动提醒**闭环，而非又一个笔记工具。

### B.2 目标与指标（北极星）
- 北极星：**周活跃记忆条目数 / 跨端续接使用率**；
- 关键指标：授权转化率（小程序→原生 App）、提醒去重命中率、续接点击率、7 日留存。

### B.3 路线图
- M1 微信小程序 + 统一登录；
- M2 中心化同步与跨端续接；
- M3 原生 App 系统级捕获（Pro）；
- M4 跨端提醒去重与体验一致性验收；
- M5 其他小程序生态扩展（Phase 2）。

### B.4 团队分工与交付物
- **产品**：PRD（docs/01）、本手册、优先级与验收；
- **设计**：设计稿件说明（docs/02）、Design Token；
- **研发**：集成方案（docs/00）落地、同步网关、Agent 层、各端客户端；
- **算法/数据**：语义合并、向量索引、问答 RAG；
- **合规**：微信授权边界、隐私撤销、不训练承诺核验。

### B.5 关键决策记录（ADR 摘要）
- ADR-1 主集成形态选微信小程序：触达与核心价值最高、成本最低；
- ADR-2 统一 `user_id` 主键：多端合并前提；
- ADR-3 提醒三通道去重：避免跨端重复打扰。

### B.6 风险与应对
- 微信合规收紧 → 最小化采集 + 强授权提示；
- 小程序无后台能力 → 打开即同步 + 订阅消息兜底；
- 原生 App 双端成本 → 跨端框架（RN/Flutter）控制投入。
